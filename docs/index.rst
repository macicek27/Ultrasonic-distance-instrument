Ultrasonic distance instrument
==============================

Contact-less distance meter with the HC-SR04 ultrasonic sensor on a Raspberry Pi
Pico W running MicroPython. The distance is shown on a 4-digit TM1637 display,
an RGB LED shows near/far and a relay switches on when an object is too close.
A push button turns on HOLD, which freezes the value on the display.

Wiring and the timing plan are described in ``README.md`` in the repository.
